Difference between <ol> and <ul> Tags

HTML me <ol> aur <ul> tags list banane ke liye use hote hain, lekin dono ka use alag-alag hota hai.

<ol> (Ordered List)

<ol> tag ordered list banane ke liye use hota hai. Isme items number ya letters ke sequence me hote hain.

Structure:

<ol>
  <li>Item 1</li>
  <li>Item 2</li>
</ol>

Example:

  1. HTML
  2. CSS
  3. JavaScript

<ul> (Unordered List)

<ul> tag unordered list banane ke liye use hota hai. Isme items bullets ke form me hote hain.

Structure:

<ul>
  <li>Item A</li>
  <li>Item B</li>
</ul>

Example:

  • Pen
  • Book
  • Notebook

Difference Summary

  • <ol> shows items in order (1, 2, 3).
  • <ul> shows items with bullets.
  • <ol> is used where sequence matters.
  • <ul> is used where order does not matter.
