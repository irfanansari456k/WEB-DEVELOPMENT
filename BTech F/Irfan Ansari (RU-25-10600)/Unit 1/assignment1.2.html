Anchor Tag in HTML

The anchor tag is used to create hyperlinks in HTML. It helps users navigate from one page to another or to an external website.

Syntax of Anchor Tag

<a href="https://www.example.com">Click Here</a>

Explanation

  • <a> : Opening anchor tag
  • href : Attribute that specifies the link address
  • https://www.example.com : Destination URL
  • Click Here : Text visible to the user
  • </a> : Closing anchor tag
