IMG Tag in HTML

The <img> tag is used to display images on a web page. It is an empty tag and does not have a closing tag.

Syntax of IMG Tag

<img src="image.jpg" alt="Sample Image">

Common Attributes of IMG Tag

  • src : Specifies the path or URL of the image.
  • alt : Provides alternative text if the image cannot be displayed.
  • width : Sets the width of the image.
  • height : Sets the height of the image.

Importance of IMG Tag

The <img> tag makes web pages more attractive and informative. It improves user experience and accessibility.
